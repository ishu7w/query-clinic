# Report surface

Operate mode. The selected direction is a comparison workbench with a shared before-and-after chart and selectable plan steps.

## Direction contract

**Thesis.** Read a database regression like a code review, with the outcome and supporting evidence together.

**Own world.** Printed diagnostic sheet. Deep teal app chrome, off-white stock, graphite text, ruled columns and precise tabular numbers. Clay belongs to candidate evidence and regression status.

**Story.** Identify the query, see the regression on an honest shared axis, inspect the changed operator, then read the SQL and measurement details.

**First viewport.** Slim utility header, full-width dark query band, broad timing chart and adjacent run metadata, then parallel plan columns. Compare and SQL tabs sit on the boundary between summary and evidence.

**Form.** Code-led workbench chosen by the user. Calibration roll reference `seed:f205571de3cf1a26`. The composition itself follows the user-selected workbench. Native scroll and immediate plan selection. On narrow screens the plans stack and retain their labels.

**Finish.** Unreviewed and undocumented is unfinished. The build ends with the finish review, verdict and design record.
